## About

Llnughyu maintains a small set of focused repositories, each with a single responsibility. Shared foundations, reusable libraries and runnable services are kept separate so that each can evolve independently.

## Pronunciation

| Name | Phonetic | IPA |
| --- | --- | --- |
| Llnughyu | luh-NOO-gyoo | `/lə.ˈnuː.ɡjuː/` |

The name divides into three parts: **Ll** (a short, unstressed *luh*), **nu** (the stressed syllable, *NOO*) and **ghyu** (a hard *gyoo*).
